01 / ANIMATION

스프라이트 시트 애니메이션

매뉴얼 07장에서는 이미지 2장(enemy.png, enemy_frame2.png)을 리스트로 직접 나열해 애니메이션을 만들었습니다. 프레임이 4장, 8장으로 늘어나면 각 프레임을 개별 파일로 관리하기보다, 큰 이미지 한 장(스프라이트 시트)에서 조각을 잘라 쓰는 방식이 더 효율적입니다.

왜 필요한가
개별 프레임을 파일마다 따로 관리하면 이미지 파일 수가 캐릭터 수 × 프레임 수만큼 늘어나 폴더가 금방 지저분해집니다. 스프라이트 시트는 한 장의 이미지에 여러 프레임을 격자로 배치해두고 필요한 부분만 잘라 쓰므로, 파일 관리가 간단해지고 이미지 로딩 횟수도 줄어듭니다.

시작 코드 스케치

sprites.py (스케치) 
class AnimatedSprite(pygame.sprite.Sprite):
    def __init__(self, sheet_path, frame_size, frame_count):
        super().__init__()
        sheet = pygame.image.load(sheet_path).convert_alpha()
        fw, fh = frame_size
        # 시트를 가로로 frame_count개 조각으로 잘라 리스트에 담기
        self.frames = [
            sheet.subsurface(pygame.Rect(i * fw, 0, fw, fh))
            for i in range(frame_count)
        ]
        self.frame_index = 0
        self.image = self.frames[0]
        self.rect = self.image.get_rect()
핵심 함수: Surface.subsurface(rect)는 원본 이미지의 일부 영역을 새 이미지 데이터 복사 없이 "참조"만으로 잘라냅니다. 07장에서 쓴 self.frames = [이미지1, 이미지2] 리스트와 순환(% len(self.frames)) 로직은 그대로 재사용하면 됩니다 — 바뀌는 것은 "프레임을 어디서 가져오는가"뿐입니다.
02 / PARTICLE EFFECT

파티클 이펙트 확장

매뉴얼 10장에서는 플레이어가 죽을 때만 Explosion 스프라이트를 표시합니다. 같은 클래스를 적이 총알에 맞아 죽는 순간에도 재사용해보세요.

왜 필요한가
적을 맞혔을 때 아무 반응이 없으면 타격감이 떨어집니다. 이미 만들어 둔 Explosion 클래스를 재사용하면 새 코드를 거의 추가하지 않고도 게임의 완성도를 크게 높일 수 있습니다.

시작 코드 스케치

main.py (스케치) 
hits = pygame.sprite.groupcollide(bullets, enemies, True, True)
for enemy_rect_center in [e.rect.center for e in hits.values()]:
    pass  # groupcollide는 이미 죽은 적을 값으로 주므로, 아래처럼 키를 순회하는 편이 안전합니다

for enemy in hits:  # hits의 key: 총알과 부딪힌 적 스프라이트들
    boom = Explosion(enemy.rect.center, size=32, duration=300)
    all_sprites.add(boom)
score += len(hits) * 10
if hits and explosion_sound:
    explosion_sound.play()
주의: groupcollide(bullets, enemies, True, True)는 충돌 즉시 두 스프라이트를 kill()합니다. Explosion은 kill()되기 전에 enemy.rect.center 좌표를 읽어와야 하므로, hits 딕셔너리를 순회하는 시점(아직 파이썬 객체 자체는 살아있음)에 좌표를 꺼내 씁니다.
03 / DELTA TIME

델타 타임 & Vector2

지금까지는 "프레임당 몇 픽셀"로 이동 속도를 정했습니다. 이 방식은 컴퓨터마다 실제 초당 프레임 수(FPS)가 조금씩 달라지면 체감 속도도 달라진다는 단점이 있습니다.

왜 필요한가
clock.tick(60)으로 60프레임을 "목표"로 삼아도, 컴퓨터 성능이나 다른 프로그램의 영향으로 실제로는 55프레임, 58프레임이 나올 수 있습니다. "픽셀/프레임" 방식은 이 경우 게임 속도가 느려지지만, "픽셀/초" 방식(델타 타임)은 프레임이 늦게 나와도 그만큼 더 많이 이동시켜 체감 속도를 일정하게 유지합니다.

시작 코드 스케치

main.py (스케치) 
# clock.tick()은 지난 프레임 이후 지나간 시간(ms)을 돌려줍니다
dt_ms = clock.tick(FPS)
dt = dt_ms / 1000   # 초 단위로 변환

# Player.update()에서: self.speed를 "초당 픽셀"로 재정의하고 dt를 곱해 이동
def update(self, keys, screen_width, dt):
    velocity = pygame.math.Vector2(0, 0)
    if keys[pygame.K_LEFT]:
        velocity.x = -self.speed   # self.speed = 300 (초당 300픽셀) 같은 값으로 변경
    if keys[pygame.K_RIGHT]:
        velocity.x = self.speed
    self.rect.x += velocity.x * dt
pygame.math.Vector2는 (x, y) 두 값을 하나의 벡터로 묶어, 방향과 속력을 함께 다룰 수 있게 해줍니다. 대각선 이동처럼 x·y를 동시에 계산해야 하는 경우 일반 숫자 두 개보다 Vector2가 훨씬 편리합니다(velocity.length(), velocity.normalize() 등).
04 / MASK COLLISION

픽셀 마스크 충돌

05장에서 배운 colliderect()는 사각형 테두리끼리만 비교합니다. 우주선이나 외계인 그림 모서리에 투명한 여백이 많으면, 실제로는 그림이 겹치지 않았는데도 충돌로 판정될 수 있습니다.

왜 필요한가
정밀한 슈팅 게임일수록 "정확히 그림이 닿았을 때만" 충돌 처리해야 플레이어가 납득할 수 있는 판정이 됩니다. pygame.mask는 이미지의 투명하지 않은 픽셀만 골라 비교하므로, 사각형보다 훨씬 실제 모양에 가까운 충돌 판정을 만들 수 있습니다.

시작 코드 스케치

sprites.py (스케치) 
class Enemy(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = load_image("enemy.png", (32, 24), (255, 61, 129))
        self.rect = self.image.get_rect(topleft=(x, y))
        self.mask = pygame.mask.from_surface(self.image)  # 투명하지 않은 픽셀 지도
main.py (스케치) 
# colliderect() 대신 pygame.sprite.spritecollide에 collided 인자로 마스크 충돌 함수 지정
hits = pygame.sprite.groupcollide(
    bullets, enemies, True, True,
    collided=pygame.sprite.collide_mask
)
주의사항: 모든 스프라이트가 self.mask 속성을 가지고 있어야 합니다 (이미지가 바뀌는 애니메이션 스프라이트라면 프레임이 바뀔 때마다 마스크도 다시 계산해야 합니다). 또한 사각형 충돌보다 계산량이 많으므로, 화면에 스프라이트가 아주 많다면 성능에 유의하세요.
05 / SAVE & LOAD

세이브/로드 (JSON)

10장의 확인 미션에서 high_score 변수를 메모리에만 두고 갱신하는 것까지 다뤘습니다. 이 값을 파일로 저장해두면, 게임을 완전히 껐다가 다시 실행해도 최고 점수가 유지됩니다.

왜 필요한가
변수는 프로그램이 종료되는 순간 사라집니다. 최고 점수·설정값처럼 다음 실행에도 남아있어야 하는 데이터는 파일에 직렬화(파이썬 객체를 텍스트/바이트로 변환)해서 저장해야 합니다. JSON은 사람이 읽기 쉽고, 파이썬 json 모듈이 표준으로 내장되어 있어 가장 간단한 선택입니다.

시작 코드 스케치

main.py (스케치) 
import json

SAVE_PATH = os.path.join(BASE_DIR, "savedata.json")

def load_high_score():
    try:
        with open(SAVE_PATH, "r", encoding="utf-8") as f:
            data = json.load(f)
        return data.get("high_score", 0)
    except (FileNotFoundError, json.JSONDecodeError):
        return 0   # 파일이 없거나 손상되었으면 0부터 시작

def save_high_score(value):
    with open(SAVE_PATH, "w", encoding="utf-8") as f:
        json.dump({"high_score": value}, f)

high_score = load_high_score()   # 게임 시작 시 한 번 불러오기

# new_game()에서 재시작 직전, 또는 GAMEOVER 진입 시:
if score > high_score:
    high_score = score
    save_high_score(high_score)
왜 try/except로 감싸나요? 게임을 처음 실행하면 저장 파일이 아직 존재하지 않습니다. FileNotFoundError를 잡아 기본값 0을 돌려주면, 첫 실행에서도 오류 없이 자연스럽게 시작할 수 있습니다.
06 / FSM

유한 상태 기계 (FSM)

10장의 game_state 문자열과 if/elif 분기는 상태가 4개(TITLE, PLAYING, EXPLODING, GAMEOVER)일 때는 충분하지만, 상태가 더 늘어나면(일시정지, 옵션 화면, 스테이지 클리어 등) 하나의 거대한 if/elif 블록이 되어 관리하기 어려워집니다.

왜 필요한가
각 상태를 별도의 클래스(Scene)로 분리하면, "이 상태에서 무슨 일이 일어나는지"를 한 파일 안에서 찾지 않고 해당 Scene 클래스만 보면 되므로 코드를 관리하기 훨씬 쉬워집니다. 이것이 게임 개발에서 흔히 쓰이는 유한 상태 기계(Finite State Machine) 패턴입니다.

시작 코드 스케치

scenes.py (스케치) 
class Scene:
    def handle_event(self, event): pass
    def update(self): pass
    def draw(self, screen): pass


class TitleScene(Scene):
    def handle_event(self, event):
        if event.type == pygame.KEYDOWN and event.key == pygame.K_RETURN:
            return "PLAYING"   # 다음에 전환할 상태 이름을 반환
        return None          # 전환 없음

    def draw(self, screen):
        title_surf = font.render("SPACE INVADERS", True, GREEN)
        screen.blit(title_surf, title_surf.get_rect(center=(WIDTH//2, 220)))


# main.py의 게임 루프는 아주 단순해집니다:
scenes = {"TITLE": TitleScene(), # "PLAYING": PlayingScene(), ...}
current = "TITLE"

while running:
    for event in pygame.event.get():
        next_state = scenes[current].handle_event(event)
        if next_state:
            current = next_state
    scenes[current].update()
    scenes[current].draw(screen)
한 번에 다 바꾸지 마세요. 기존 if/elif 코드가 잘 동작하고 있다면, 상태를 하나씩만 Scene 클래스로 옮겨보며 점진적으로 리팩터링하는 것을 권장합니다. 한꺼번에 전부 바꾸려다 게임이 아예 동작하지 않는 상태로 오래 머무는 것보다, 작동하는 상태를 유지하며 조금씩 개선하는 편이 안전합니다.

일시정지(Pause) 기능 추가하기

FSM 구조를 쓰면 일시정지는 상태 하나를 추가하는 것만으로 해결됩니다. 핵심 아이디어는 "PAUSED 상태에서는 update()를 아예 호출하지 않는다"는 것입니다. 화면 갱신을 멈추면 플레이어·적·총알의 위치가 그 순간 그대로 얼어붙습니다.

scenes.py (추가) 
class PausedScene(Scene):
    def __init__(self, font, playing_scene):
        self.font = font
        self.playing = playing_scene   # 멈춘 순간의 화면을 계속 보여주기 위해 참조 공유

    def handle_event(self, event):
        if event.type == pygame.KEYDOWN and event.scancode == pygame.KSCAN_P:
            return "PLAYING"   # 다시 누르면 재개
        return None

    def update(self, dt):
        return None   # 아무것도 갱신하지 않음 = 게임이 완전히 멈춤

    def draw(self, screen):
        self.playing.draw(screen)   # 멈춘 상태의 게임 화면을 그대로 다시 그리고

        overlay = pygame.Surface((WIDTH, HEIGHT), pygame.SRCALPHA)
        overlay.fill((0, 0, 0, 160))       # 반투명 검은 막을 그 위에 덮기
        screen.blit(overlay, (0, 0))

        text = self.font.render("PAUSED", True, GREEN)
        hint = self.font.render("PRESS P TO RESUME", True, (200,200,200))
        screen.blit(text, text.get_rect(center=(WIDTH//2, HEIGHT//2 - 20)))
        screen.blit(hint, hint.get_rect(center=(WIDTH//2, HEIGHT//2 + 20)))

PlayingScene.handle_event에 P키 입력을 감지해 "PAUSED"로 전환하는 코드 한 줄만 추가하면 연결이 끝납니다.

scenes.py (PlayingScene.handle_event 안에 추가) 
def handle_event(self, event):
    if event.type == pygame.KEYDOWN and event.scancode == pygame.KSCAN_P:
        return "PAUSED"
    # ... 기존 스페이스바 발사 코드 ...
    return None
main.py (scenes 딕셔너리에 추가) 
scenes = {
    "TITLE": title,
    "PLAYING": playing,
    "PAUSED": PausedScene(font, playing),   # 추가
    "EXPLODING": ExplodingScene(playing),
    "GAMEOVER": GameOverScene(font, playing),
}
왜 dt가 아니라 update() 호출 자체를 막나요? dt를 0으로 넘겨도 이동은 멈추지만, Explosion이나 Enemy의 애니메이션 타이머는 pygame.time.get_ticks()(실제 시계)를 직접 참조하므로 dt와 무관하게 계속 흘러갑니다. PausedScene.update()가 아무것도 호출하지 않도록 하는 것이 모든 것을 확실하게 멈추는 유일한 방법입니다.
일시정지 중에 발생한 적 발사 타이머는 어떻게 되나요? pygame.time.set_timer로 등록한 ENEMY_FIRE_EVENT는 게임 상태와 무관하게 계속 발생합니다. 하지만 PausedScene은 이 이벤트를 처리하지 않으므로(부모 Scene.handle_event가 None을 반환) 자연스럽게 무시됩니다 — 별도 처리를 하지 않아도 됩니다.
⚠ 한글 입력기(IME)가 켜져 있으면 P키(혹은 다른 알파벳 키)가 씹힐 수 있습니다. pygame(SDL2)은 창을 만들면 기본적으로 "텍스트 입력 모드"가 켜져 있어, 운영체제가 키를 게임에 바로 전달하지 않고 IME(한글 조합기)를 먼저 거치게 합니다. 이 게임은 실제 문자 입력이 필요 없으므로, 초기화 직후 아래 한 줄로 이 동작을 꺼두면 어떤 입력 모드에서도 항상 정상 동작합니다.
main.py (초기화 부분에 추가) 
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.key.stop_text_input()   # IME가 키 입력을 가로채지 않도록 끄기
맥에서는 이것만으로 부족할 수 있습니다. stop_text_input()은 "한글 조합 중 텍스트 입력을 가로채는" 문제만 막아줍니다. 하지만 macOS의 한글 입력 소스는 단순한 IME 오버레이가 아니라 키보드 배열 자체를 통째로 바꾸는 방식이라, 한글 모드에서는 물리적인 P키를 눌러도 pygame이 인식하는 event.key(논리적 키 값)가 pygame.K_p가 아닌 다른 값으로 들어옵니다. 그래서 한/영 전환을 하기 전까지는 event.key == pygame.K_p 비교가 계속 실패했던 것입니다.

해결책은 "어떤 문자가 입력되었는가"(event.key) 대신 "키보드의 어느 물리적 위치가 눌렸는가"(event.scancode)를 검사하는 것입니다. 스캔코드는 키보드 배열이나 입력 언어와 무관하게, 물리적인 P 위치의 키를 누르면 항상 같은 값을 돌려줍니다.

레이아웃 독립적인 키 입력 · scancode
event.scancode
매개변수— (KEYDOWN/KEYUP 이벤트 객체의 속성이며 함수가 아닙니다.)
반환값int — 눌린 키의 물리적 위치를 나타내는 값. 키보드 배열(QWERTY, 한글 2벌식 등)이나 현재 입력 언어와 무관하게, 같은 위치의 키는 항상 같은 scancode를 돌려줍니다.
주의사항event.key(논리적 키 값·문자)와는 다른 개념입니다. 방향키·스페이스·엔터처럼 입력 언어에 영향받지 않는 키는 event.key로도 충분하지만, 알파벳 키를 게임 조작키로 쓸 때는 scancode를 쓰는 것이 안전합니다.
pygame.KSCAN_P (외 KSCAN_A ~ KSCAN_Z 등)
매개변수— (함수가 아니라 각 물리적 키 위치에 대응하는 정수 상수입니다.)
반환값— event.scancode와 비교하는 값으로 사용합니다: event.scancode == pygame.KSCAN_P.
주의사항이름이 K_p가 아니라 KSCAN_P라는 점에 주의하세요. 앞의 K_ 상수들과 헷갈리기 쉽습니다.

import os, json, random, pygame

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
IMG_DIR = os.path.join(BASE_DIR, "assets", "images")
SND_DIR = os.path.join(BASE_DIR, "assets", "sounds")
SAVE_PATH = os.path.join(BASE_DIR, "savedata.json")


def load_image(filename, size, fallback_color):
    try:
        img = pygame.image.load(os.path.join(IMG_DIR, filename)).convert_alpha()
        return pygame.transform.scale(img, size)
    except (pygame.error, FileNotFoundError):
        surf = pygame.Surface(size, pygame.SRCALPHA)
        surf.fill(fallback_color)
        return surf


def load_sound(filename):
    try:
        return pygame.mixer.Sound(os.path.join(SND_DIR, filename))
    except pygame.error:
        return None


def load_high_score():
    try:
        with open(SAVE_PATH, "r", encoding="utf-8") as f:
            return json.load(f).get("high_score", 0)
    except (FileNotFoundError, json.JSONDecodeError):
        return 0


def save_high_score(value):
    with open(SAVE_PATH, "w", encoding="utf-8") as f:
        json.dump({"high_score": value}, f)


# --- 모든 스프라이트는 (keys, screen_width, dt) 시그니처로 통일합니다.
#     Player만 keys/screen_width를 실제로 쓰고, 나머지는 dt만 사용합니다. ---

class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = load_image("player.png", (40, 30), (61, 255, 154))
        self.rect = self.image.get_rect(center=(x, y))
        self.mask = pygame.mask.from_surface(self.image)      # 04. 마스크 충돌
        self.pos = pygame.math.Vector2(self.rect.center)       # 03. 델타타임: 실수 좌표 보관
        self.speed = 260   # 초당 260픽셀

    def update(self, keys, screen_width, dt):
        velocity = pygame.math.Vector2(0, 0)
        if keys[pygame.K_LEFT]:
            velocity.x = -self.speed
        if keys[pygame.K_RIGHT]:
            velocity.x = self.speed
        self.pos += velocity * dt
        half_w = self.rect.width / 2
        self.pos.x = max(half_w, min(screen_width - half_w, self.pos.x))
        self.rect.center = self.pos


class Bullet(pygame.sprite.Sprite):
    def __init__(self, x, y, filename="bullet_player.png", color=(61,255,154), direction=-1):
        super().__init__()
        self.image = load_image(filename, (4, 12), color)
        if direction == -1:
            self.rect = self.image.get_rect(midbottom=(x, y))  # 위로: 꼬리를 시작점에 맞춤
        else:
            self.rect = self.image.get_rect(midtop=(x, y))     # 아래로: 머리를 시작점에 맞춤
        self.mask = pygame.mask.from_surface(self.image)
        self.pos = pygame.math.Vector2(self.rect.center)
        self.speed = 600   # 초당 600픽셀
        self.direction = direction

    def update(self, keys, screen_width, dt):
        self.pos.y += self.speed * self.direction * dt
        self.rect.center = self.pos
        if self.rect.bottom < 0 or self.rect.top > 700:
            self.kill()


class Enemy(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.frames = [                                        # 01. 애니메이션
            load_image("enemy.png", (32, 24), (255, 61, 129)),
            load_image("enemy_frame2.png", (32, 24), (255, 61, 129)),
        ]
        self.frame_index = 0
        self.image = self.frames[0]
        self.rect = self.image.get_rect(topleft=(x, y))
        self.mask = pygame.mask.from_surface(self.image)      # 04. 마스크 충돌
        self.pos = pygame.math.Vector2(self.rect.topleft)      # 03. 델타타임
        self.direction = 1
        self.speed = 60    # 초당 60픽셀
        self.anim_timer = pygame.time.get_ticks() + random.randint(0, 500)
        self.anim_interval = 500

    def update(self, keys, screen_width, dt):
        self.pos.x += self.speed * self.direction * dt
        self.rect.topleft = self.pos

        now = pygame.time.get_ticks()
        if now - self.anim_timer > self.anim_interval:
            self.anim_timer = now
            self.frame_index = (self.frame_index + 1) % len(self.frames)
            center = self.rect.center
            self.image = self.frames[self.frame_index]
            self.mask = pygame.mask.from_surface(self.image)  # 프레임이 바뀌면 마스크도 새로 계산
            self.rect = self.image.get_rect(center=center)
            self.pos = pygame.math.Vector2(self.rect.topleft)


class Explosion(pygame.sprite.Sprite):
    def __init__(self, center, size=48, duration=500):
        super().__init__()
        self.image = load_image("explosion.png", (size, size), (255, 200, 87))
        self.rect = self.image.get_rect(center=center)
        self.spawn_time = pygame.time.get_ticks()
        self.duration = duration

    def update(self, keys, screen_width, dt):
        if pygame.time.get_ticks() - self.spawn_time > self.duration:
            self.kill()

import random, pygame
from sprites import Player, Bullet, Enemy, Explosion

WIDTH, HEIGHT = 480, 600
GREEN = (61, 255, 154)
MAGENTA = (255, 61, 129)
AMBER = (255, 200, 87)


class Scene:
    # 모든 씬(화면)이 공통으로 갖는 세 가지 동작. 필요한 것만 자식 클래스에서 오버라이드합니다.
    def handle_event(self, event):
        return None   # 다음 상태 이름을 반환하면 전환, None이면 그대로 유지

    def update(self, dt):
        return None

    def draw(self, screen):
        pass


class TitleScene(Scene):
    def __init__(self, font, high_score):
        self.font = font
        self.high_score = high_score

    def handle_event(self, event):
        if event.type == pygame.KEYDOWN and event.key == pygame.K_RETURN:
            return "PLAYING"
        return None

    def draw(self, screen):
        title = self.font.render("SPACE INVADERS", True, GREEN)
        hint = self.font.render("PRESS ENTER TO START", True, (120,120,120))
        hi = self.font.render(f"HIGH SCORE {self.high_score}", True, AMBER)  # 05. 세이브/로드
        screen.blit(title, title.get_rect(center=(WIDTH//2, 200)))
        screen.blit(hint, hint.get_rect(center=(WIDTH//2, 260)))
        screen.blit(hi, hi.get_rect(center=(WIDTH//2, 310)))


class PlayingScene(Scene):
    def __init__(self, screen_width, font, enemy_fire_event, sounds):
        self.screen_width = screen_width
        self.font = font
        self.enemy_fire_event = enemy_fire_event
        self.sounds = sounds
        self.boom = None
        self.reset()

    def reset(self):
        self.all_sprites = pygame.sprite.Group()
        self.bullets = pygame.sprite.Group()
        self.enemy_bullets = pygame.sprite.Group()
        self.enemies = pygame.sprite.Group()

        self.player = Player(WIDTH // 2, HEIGHT - 40)
        self.all_sprites.add(self.player)
        self.life_icon = pygame.transform.scale(self.player.image, (20, 15))

        for row in range(4):
            for col in range(8):
                e = Enemy(40 + col * 50, 60 + row * 40)
                self.enemies.add(e); self.all_sprites.add(e)

        self.score, self.lives = 0, 3

    def handle_event(self, event):
        if event.type == pygame.KEYDOWN and event.scancode == pygame.KSCAN_P:
            return "PAUSED"
        if event.type == pygame.KEYDOWN and event.key == pygame.K_SPACE:
            b = Bullet(self.player.rect.centerx, self.player.rect.top)
            self.bullets.add(b); self.all_sprites.add(b)
            if self.sounds["shoot"]: self.sounds["shoot"].play()
        if event.type == self.enemy_fire_event and self.enemies:
            shooter = random.choice(self.enemies.sprites())
            eb = Bullet(shooter.rect.centerx, shooter.rect.bottom,
                        filename="bullet_enemy.png", color=AMBER, direction=1)
            self.enemy_bullets.add(eb); self.all_sprites.add(eb)
        return None

    def update(self, dt):
        keys = pygame.key.get_pressed()
        self.all_sprites.update(keys, self.screen_width, dt)   # 03. 델타타임 전달

        edge_hit = any(e.rect.right > self.screen_width or e.rect.left < 0 for e in self.enemies)
        if edge_hit:
            for e in self.enemies:
                e.direction *= -1
                e.rect.y += 14
                e.pos = pygame.math.Vector2(e.rect.topleft)

        # 04. 마스크 기반 정밀 충돌 (사각형이 아니라 실제 그림 모양으로 판정)
        hits = pygame.sprite.groupcollide(
            self.bullets, self.enemies, True, True, collided=pygame.sprite.collide_mask
        )
        for enemy in hits:            # 02. 파티클 이펙트 확장: 적이 죽은 위치마다 폭발 표시
            self.all_sprites.add(Explosion(enemy.rect.center, size=32, duration=300))
        self.score += len(hits) * 10
        if hits and self.sounds["explosion"]:
            self.sounds["explosion"].play()

        hit_by_bullet = pygame.sprite.spritecollide(self.player, self.enemy_bullets, True, collided=pygame.sprite.collide_mask)
        hit_by_enemy = pygame.sprite.spritecollide(self.player, self.enemies, True, collided=pygame.sprite.collide_mask)   # 적 본체와의 직접 충돌
        if hit_by_bullet or hit_by_enemy:
            self.lives -= 1
            if self.sounds["hit"]: self.sounds["hit"].play()

        if self.lives <= 0:
            self.boom = Explosion(self.player.rect.center)
            self.all_sprites.add(self.boom)
            self.player.kill()
            if self.sounds["explosion"]: self.sounds["explosion"].play()
            return "EXPLODING"
        if len(self.enemies) == 0:
            return "GAMEOVER"
        return None

    def draw(self, screen):
        self.all_sprites.draw(screen)
        screen.blit(self.font.render(f"SCORE {self.score}", True, GREEN), (10, 10))
        for i in range(self.lives):
            screen.blit(self.life_icon, (WIDTH - 30 - i * 26, 10))


class ExplodingScene(Scene):
    def __init__(self, playing_scene):
        self.playing = playing_scene   # 폭발 재생 중에도 총알·적을 계속 보여주기 위해 참조 공유

main.py 
import pygame
from sprites import load_high_score, save_high_score, load_sound
from scenes import TitleScene, PlayingScene, PausedScene, ExplodingScene, GameOverScene

pygame.init()
WIDTH, HEIGHT = 480, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("스페이스 인베이더 (통합 예시)")
pygame.key.stop_text_input()   # 한글 등 IME가 P/스페이스바 같은 키 입력을 가로채지 않도록 끄기
clock = pygame.time.Clock()
font = pygame.font.SysFont("consolas", 24)
FPS = 60

ENEMY_FIRE_EVENT = pygame.USEREVENT + 1
pygame.time.set_timer(ENEMY_FIRE_EVENT, 900)

sounds = {
    "shoot": load_sound("shoot.wav"),
    "explosion": load_sound("explosion.wav"),
    "hit": load_sound("hit.wav"),
}

high_score = load_high_score()   # 05. 세이브/로드: 이전에 저장된 최고 점수 불러오기

playing = PlayingScene(WIDTH, font, ENEMY_FIRE_EVENT, sounds)
title = TitleScene(font, high_score)
scenes = {
    "TITLE": title,
    "PLAYING": playing,
    "PAUSED": PausedScene(font, playing),
    "EXPLODING": ExplodingScene(playing),
    "GAMEOVER": GameOverScene(font, playing),
}
current = "TITLE"
running = True

while running:
    dt = clock.tick(FPS) / 1000   # 03. 델타타임: 이번 프레임에 걸린 시간(초)

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        next_state = scenes[current].handle_event(event)
        if next_state:
            if next_state == "PLAYING":
                playing.reset()   # 새 게임 시작(첫 시작이든 재시작이든 동일)
            current = next_state

    next_state = scenes[current].update(dt)
    if next_state:
        if next_state == "GAMEOVER" and playing.score > high_score:
            high_score = playing.score
            save_high_score(high_score)   # 05. 세이브/로드: 파일에 최고 점수 기록
            title.high_score = high_score
        current = next_state

    screen.fill((10, 10, 20))
    scenes[current].draw(screen)
    pygame.display.flip()

pygame.quit()
