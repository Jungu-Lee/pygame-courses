0개요 & 학습 목표

이 자료는 Pygame으로 게임을 만들 때 자주 등장하는 두 가지 기본 패턴을 직접 실행하며 익히기 위한 실습 자료입니다.

실습배우는 내용핵심 개념
1. 카운트다운 화면 화면에 5 → 4 → 3 → 2 → 1이 1초 간격으로 표시된 뒤 "GO!"가 나타나는 연출 pygame.time.set_timer, 커스텀 이벤트, 폰트 렌더링, pygame.mixer.Sound
2. 캐릭터 이동 & 애니메이션 방향키를 누르면 캐릭터가 해당 방향으로 이동하고, 4방향 걷기 애니메이션이 재생 스프라이트 시트 슬라이싱, subsurface, 키 입력 상태, 애니메이션 타이밍

두 실습 모두 완성된 예제 코드와, 코드에서 사용하는 이미지(스프라이트 시트)·효과음 파일을 그대로 다운로드해서 바로 실행해볼 수 있도록 준비했습니다.

1준비물 & 폴더 구조

설치

pip install pygame-ce
pygame-ce — 이 자료는 pygame이 아니라 커뮤니티 유지보수 포크인 pygame-ce(Community Edition)를 사용합니다. 패키지 이름만 pygame-ce일 뿐, 코드에서는 그대로 import pygame으로 불러오면 됩니다. 다만 pygame과 pygame-ce를 같은 가상환경에 함께 설치하면 충돌하므로, 기존에 pygame이 설치되어 있다면 먼저 pip uninstall pygame으로 제거한 뒤 pygame-ce를 설치하세요.

2카운트다운 원리

게임을 시작하기 전 "3, 2, 1, GO!" 같은 카운트다운 연출은 매우 흔합니다. 이걸 만드는 방법은 여러 가지가 있지만, 이번 실습에서는 Pygame의 커스텀 타이머 이벤트를 사용합니다.

왜 time.sleep()을 쓰면 안 될까?

time.sleep(1)로 1초씩 멈추면 코드는 간단해 보이지만, 그 1초 동안 게임 전체가 멈춰버립니다. 창을 옮기거나 닫기 버튼을 눌러도 반응하지 않고, 다른 애니메이션도 함께 멈춥니다. Pygame 게임은 항상 초당 60번 정도 도는 game loop를 유지해야 하기 때문에, "1초 기다리기"도 game loop를 멈추지 않는 방식으로 구현해야 합니다.

pygame.time.set_timer(event, millis)
파라미터event — 주기적으로 발생시킬 이벤트(보통 pygame.event.Event(pygame.USEREVENT+1) 형태) / millis — 반복 간격(밀리초)
동작호출 이후 millis마다 지정한 이벤트가 이벤트 큐에 자동으로 쌓입니다. game loop는 멈추지 않고 계속 돌면서, 이벤트 루프에서 이 이벤트를 확인해 처리합니다.
주의타이머를 멈추려면 같은 이벤트 번호로 millis를 0으로 주고 다시 호출해야 합니다. (pygame.time.set_timer(COUNTDOWN_EVENT, 0))
대안 — 좀 더 세밀한 제어가 필요하다면 pygame.time.get_ticks()로 현재까지 흐른 시간(ms)을 직접 읽어와서 "마지막으로 숫자가 바뀐 시점 + 1000ms"와 비교하는 방식도 많이 씁니다. 이 방법은 이후 심화 자료에서 델타 타임(delta time)과 함께 다룹니다.

3실습 1 전체 코드

아래 코드를 그대로 복사해서 countdown_demo.py로 저장하고, 같은 위치에 assets 폴더를 두면 바로 실행됩니다.

countdown_demo.py
# ============================================================
# 실습 1 - 카운트다운 화면
# ------------------------------------------------------------
# 목표: 게임 루프를 멈추지 않으면서 5 -> 4 -> 3 -> 2 -> 1이
#       1초 간격으로 표시되고, 마지막에 "GO!"가 나타나는 연출을
#       pygame.time.set_timer()로 구현한다.
# ============================================================

import pygame
import sys

# ----- 초기화 -----
# pygame.init(): 디스플레이, 폰트 등 pygame의 모든 하위 모듈을
# 사용 가능한 상태로 준비시킨다. 다른 pygame 함수보다 먼저 호출해야 한다.
pygame.init()
# 효과음(사운드)을 재생하려면 mixer 모듈도 별도로 초기화해야 한다.
pygame.mixer.init()

WIDTH, HEIGHT = 640, 480  # 게임 창 크기(픽셀)
screen = pygame.display.set_mode((WIDTH, HEIGHT))  # 실제 창 생성, 그릴 대상 Surface 반환
pygame.display.set_caption("카운트다운 데모")  # 창 제목표시줄 문구
clock = pygame.time.Clock()  # 프레임 속도를 재고 제한하는 데 쓰는 시계 객체

# ----- 리소스 로드 -----
# SysFont(폰트이름, 크기, bold=굵게여부): 시스템에 설치된 폰트를 불러온다.
# 한글이 깨지지 않으려면 한글을 지원하는 폰트 이름을 지정해야 한다.
font_big = pygame.font.SysFont("malgungothic", 120, bold=True)   # 큰 숫자용
font_small = pygame.font.SysFont("malgungothic", 40)             # 안내 문구용

# pygame.mixer.Sound(): 효과음 파일을 불러온다. .play()를 호출하면 즉시 재생된다.
beep_sound = pygame.mixer.Sound("assets/beep.wav")  # 숫자가 바뀔 때 재생
go_sound = pygame.mixer.Sound("assets/go.wav")      # GO! 표시될 때 재생

# ----- 커스텀 이벤트: 1초마다 발생 -----
# pygame.USEREVENT는 "개발자가 자유롭게 사용할 수 있는 이벤트 번호"의 시작값이다.
# 여기에 정수를 더해서 나만의 이벤트 종류를 여러 개 정의할 수 있다.
# (예: USEREVENT+1은 카운트다운용, USEREVENT+2는 다른 용도 등으로 구분 가능)
COUNTDOWN_EVENT = pygame.USEREVENT + 1

# pygame.time.set_timer(이벤트, 밀리초)
# 호출 이후 지정한 밀리초(여기서는 1000ms = 1초)마다 COUNTDOWN_EVENT가
# 이벤트 큐에 자동으로 쌓인다. time.sleep()과 달리 game loop 자체를
# 멈추지 않기 때문에, 창 반응성이나 다른 애니메이션에 영향을 주지 않는다.
pygame.time.set_timer(COUNTDOWN_EVENT, 1000)

count = 5           # 현재 화면에 표시할 숫자 (5부터 시작해서 1까지 감소)
show_go = False      # True가 되면 숫자 대신 "GO!"를 표시
running = True       # 게임 루프를 계속 돌릴지 여부

# ============================================================
# 게임 루프 (Game Loop)
# 이 while문 한 바퀴 = 한 프레임. "이벤트 처리 -> 상태 갱신 -> 그리기"를 반복한다.
# ============================================================
while running:
    # clock.tick(60): 이전 프레임 이후 흐른 시간을 계산하고,
    # 초당 60프레임을 넘지 않도록 필요한 만큼 자동으로 대기(지연)한다.
    clock.tick(60)

    # ----- 이벤트 처리 -----
    # 발생한 이벤트를 큐에서 하나씩 꺼내서 종류에 따라 다르게 반응한다.
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            # 창의 X 버튼을 눌렀을 때 발생
            running = False

        elif event.type == COUNTDOWN_EVENT:
            # set_timer()로 등록해둔 "1초마다" 발생하는 이벤트가 여기로 들어온다.
            if count > 1:
                count -= 1          # 숫자를 하나 줄인다 (5->4->3->2->1)
                beep_sound.play()   # 숫자가 바뀔 때마다 짧은 효과음 재생
            elif count == 1:
                # 1에서 더 내려갈 곳이 없으므로, "GO!" 상태로 전환한다.
                count = 0
                show_go = True
                go_sound.play()
                # 더 이상 타이머 이벤트가 필요 없으므로, 같은 이벤트 번호로
                # 밀리초를 0으로 주면 타이머가 꺼진다. 이 처리를 빼먹으면
                # GO! 화면이 나온 뒤에도 계속 이벤트가 쌓이게 된다.
                pygame.time.set_timer(COUNTDOWN_EVENT, 0)

        elif event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            # ESC 키를 누른 "순간"에만 한 번 발생하는 이벤트
            running = False

    # ----- 화면 그리기 -----
    # 매 프레임 이전 그림을 지우기 위해 배경색으로 화면 전체를 먼저 채운다.
    screen.fill((25, 28, 38))

    if not show_go:
        # Font.render(문자열, antialias, 색상): 텍스트가 그려진 새 Surface를 반환한다.
        # antialias=True로 주면 글자 테두리가 부드럽게 처리된다.
        text_surf = font_big.render(str(count), True, (255, 220, 80))
    else:
        text_surf = font_big.render("GO!", True, (100, 220, 140))

    # get_rect(center=...): 텍스트 Surface 크기에 맞는 Rect를 만들되,
    # 그 중심을 화면 정중앙(WIDTH//2, HEIGHT//2)에 오도록 배치한다.
    text_rect = text_surf.get_rect(center=(WIDTH // 2, HEIGHT // 2))
    screen.blit(text_surf, text_rect)  # 화면에 텍스트 이미지를 실제로 그려 넣는다.

    hint = font_small.render("ESC 키를 누르면 종료됩니다", True, (180, 180, 190))
    screen.blit(hint, hint.get_rect(center=(WIDTH // 2, HEIGHT - 40)))

    # ----- 화면 갱신 -----
    # 지금까지 screen에 그린 내용을 실제 창에 반영(출력)한다.
    # flip()을 호출하기 전까지는 화면에 아무것도 보이지 않는다.
    pygame.display.flip()

pygame.quit()
sys.exit()

실행하면 화면 정중앙에 5 → 4 → 3 → 2 → 1이 1초 간격으로 노란색으로 표시되고, 마지막에 초록색 "GO!"가 나타나며 멈춥니다. 숫자가 바뀔 때마다 "삑" 효과음이, GO 순간에는 다른 효과음이 재생됩니다.

4코드 설명

① 커스텀 이벤트 만들기

COUNTDOWN_EVENT = pygame.USEREVENT + 1
pygame.time.set_timer(COUNTDOWN_EVENT, 1000)

pygame.USEREVENT는 "개발자가 자유롭게 쓸 수 있는 이벤트 번호"의 시작값입니다. 여기에 정수를 더해서 나만의 이벤트 종류를 여러 개 만들 수 있습니다. (예: USEREVENT+1은 카운트다운용, USEREVENT+2는 다른 용도 등)

② 이벤트 루프에서 처리하기

elif event.type == COUNTDOWN_EVENT:
    if count > 1:
        count -= 1
        beep_sound.play()
    elif count == 1:
        count = 0
        show_go = True
        go_sound.play()
        pygame.time.set_timer(COUNTDOWN_EVENT, 0)

매 프레임 pygame.event.get()으로 쌓인 이벤트를 순회하다가, 우리가 등록한 COUNTDOWN_EVENT가 들어오면 숫자를 하나 줄이고 효과음을 재생합니다. 1에 도달하면 show_go 플래그를 켜고, 더 이상 이벤트가 필요 없으므로 타이머를 꺼줍니다. 이 부분을 빼먹으면 GO! 화면이 나온 뒤에도 타이머 이벤트가 계속 쌓입니다.

③ 텍스트 렌더링

Font.render(text, antialias, color)
반환값글자가 그려진 새로운 Surface 객체. 이 Surface를 screen.blit()로 화면에 붙여넣습니다.
파라미터antialias를 True로 주면 글자 테두리가 부드럽게 처리됩니다.
주의매 프레임 render()를 새로 호출하는 것은 비용이 있지만, 텍스트가 자주 바뀌는 경우(카운트다운처럼)라면 이 정도는 문제되지 않습니다. 반대로 절대 안 바뀌는 텍스트는 루프 밖에서 한 번만 렌더링해서 재사용하는 것이 좋습니다.

④ 효과음 재생

pygame.mixer.Sound("경로")로 사운드 파일을 불러온 뒤 .play()를 호출하면 즉시 재생됩니다. pygame.mixer.music과 달리 Sound 객체는 여러 개를 동시에, 짧게 반복 재생하는 효과음(SFX)에 적합합니다.

5스프라이트 & 애니메이션 원리

캐릭터가 "걷는 것처럼 보이게" 하려면 캐릭터의 여러 자세를 그린 이미지 여러 장을 빠르게 번갈아 보여줘야 합니다. 이렇게 여러 프레임 이미지를 한 장의 큰 이미지에 격자로 모아둔 것을 스프라이트 시트(Sprite Sheet)라고 부릅니다.

이번 실습에서 사용하는 스프라이트 시트는 4행 × 3열 구조입니다.

행(위→아래): 아래 / 왼쪽 / 오른쪽 / 위  |  열(왼→오): 왼발 내밈 / 서기(idle) / 오른발 내밈

핵심 아이디어 두 가지

구분설명
① 어떤 칸을 자를지캐릭터의 방향(행 번호)과 애니메이션 진행 정도(열 번호)로 결정 → Surface.subsurface(rect)
② 언제 다음 칸으로 넘어갈지매 프레임 시간을 누적하다가, 일정 시간(예: 120ms)이 지나면 다음 프레임으로 인덱스만 바꿔줌
Surface.subsurface(rect)
파라미터rect — 원본 이미지에서 잘라낼 사각형 영역 (pygame.Rect(x, y, width, height))
반환값원본 이미지의 일부 영역만 보여주는 새로운 Surface. 원본과 메모리를 공유합니다.
주의반환된 Surface는 원본에 종속되어 있어 이후 pygame.transform.scale() 등으로 가공하려면 .copy()를 먼저 호출해 독립된 Surface로 만드는 것이 안전합니다.

키보드 입력을 매 프레임 확인하기

pygame.key.get_pressed()
반환값모든 키의 눌림 상태를 담은 리스트 형태의 객체. keys[pygame.K_LEFT]처럼 인덱싱하면 해당 키가 현재 눌려있는지 True/False로 확인 가능
언제 쓰나"누르고 있는 동안 계속 이동"처럼 지속적인 입력이 필요할 때. (반대로 KEYDOWN 이벤트는 "누르는 순간 한 번만" 반응할 때 사용)

6실습 2 전체 코드

player_movement_demo.py
# ============================================================
# 실습 2 - 캐릭터 이동 애니메이션
# ------------------------------------------------------------
# 목표: 방향키를 누르면 캐릭터가 해당 방향으로 이동하고,
#       4방향(위/아래/좌/우) 걷기 애니메이션이 함께 재생되도록
#       스프라이트 시트를 잘라 쓰는 방법을 익힌다.
# ============================================================

import pygame
import sys

pygame.init()
pygame.mixer.init()

WIDTH, HEIGHT = 640, 480
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("캐릭터 이동 애니메이션 데모")
clock = pygame.time.Clock()

FRAME_SIZE = 48   # 스프라이트 시트 한 칸의 가로/세로 크기(픽셀)
SCALE = 2         # 화면에 그릴 때 몇 배로 확대할지 (원본이 작아서 키워서 보여줌)

# convert_alpha(): PNG의 투명 정보를 화면 포맷에 맞게 변환해서 그리기 속도를 높인다.
spritesheet = pygame.image.load("assets/player_spritesheet.png").convert_alpha()
step_sound = pygame.mixer.Sound("assets/step.wav")  # 발이 땅에 닿을 때 재생할 효과음

# ----- 스프라이트 시트에서 방향별 "행(row)" 번호 -----
# 이 실습에서 쓰는 스프라이트 시트는 4행 x 3열 구조이다.
#   행: 0=아래, 1=왼쪽, 2=오른쪽, 3=위
#   열: 0=왼발 내밈, 1=서기(idle), 2=오른발 내밈
DIRECTIONS = {
    "down": 0,
    "left": 1,
    "right": 2,
    "up": 3,
}


def get_frame(direction, frame_index):
    """
    스프라이트 시트에서 (direction, frame_index)에 해당하는
    이미지 한 칸만 잘라내어 반환한다.

    direction   : "down"/"left"/"right"/"up" 중 하나 -> 행 번호로 변환
    frame_index : 0, 1, 2 중 하나 -> 열 번호로 그대로 사용
    """
    row = DIRECTIONS[direction]
    col = frame_index

    # pygame.Rect(x, y, width, height): 시트에서 잘라낼 사각형 영역.
    # 행/열 번호에 한 칸 크기(FRAME_SIZE)를 곱하면 그 칸의 좌상단 좌표가 된다.
    rect = pygame.Rect(col * FRAME_SIZE, row * FRAME_SIZE, FRAME_SIZE, FRAME_SIZE)

    # subsurface(rect): 원본 이미지의 "일부 영역만 보여주는" 새 Surface를 반환한다.
    # 원본과 메모리를 공유하기 때문에, 이후 scale() 등으로 별도 가공하려면
    # .copy()로 독립된 Surface를 먼저 만들어두는 것이 안전하다.
    frame = spritesheet.subsurface(rect).copy()

    # transform.scale(이미지, (가로,세로)): 이미지 크기를 원하는 크기로 바꾼다.
    # 원본이 48x48로 작으므로 SCALE배 확대해서 화면에서 잘 보이게 한다.
    frame = pygame.transform.scale(frame, (FRAME_SIZE * SCALE, FRAME_SIZE * SCALE))
    return frame


class Player:
    """캐릭터의 위치, 방향, 애니메이션 상태를 모두 관리하는 클래스."""

    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.speed = 4              # 한 프레임당 이동 픽셀 수
        self.direction = "down"     # 현재 바라보는 방향 (처음엔 아래를 봄)
        self.moving = False         # 지금 움직이는 중인지 여부

        # 애니메이션 프레임 진행 순서: 왼발 - 서기 - 오른발 - 서기 반복
        # (0,1,2,1 순서로 재생하면 자연스러운 좌우 교차 걸음이 됨)
        self.anim_frames = [0, 1, 2, 1]
        self.anim_index = 0     # anim_frames 리스트 안에서 현재 몇 번째인지
        self.anim_timer = 0     # 마지막으로 프레임이 바뀐 뒤 흐른 시간(ms) 누적
        self.anim_speed = 120   # 몇 ms마다 다음 프레임으로 넘어갈지

    def handle_input(self, dt):
        """
        방향키 입력을 확인해서 이동시키고, 애니메이션도 함께 갱신한다.
        dt: 이전 프레임 이후 흐른 시간(ms). clock.tick()의 반환값을 그대로 받는다.
        """
        # get_pressed(): 모든 키의 "현재 눌림 상태"를 담은 리스트 형태 객체.
        # 이벤트(KEYDOWN)와 달리, 키를 누르고 있는 "동안 계속" True를 유지한다.
        keys = pygame.key.get_pressed()
        dx = dy = 0

        # elif로 연결했기 때문에 한 번에 한 방향으로만 이동한다.
        # (대각선 이동을 지원하려면 elif 대신 각각 독립된 if로 검사해야 함 - 심화 주제)
        if keys[pygame.K_LEFT]:
            dx = -self.speed
            self.direction = "left"
        elif keys[pygame.K_RIGHT]:
            dx = self.speed
            self.direction = "right"
        elif keys[pygame.K_UP]:
            dy = -self.speed
            self.direction = "up"
        elif keys[pygame.K_DOWN]:
            dy = self.speed
            self.direction = "down"

        # dx 또는 dy가 0이 아니면(=방향키 중 하나라도 눌려 있으면) 움직이는 중으로 판단.
        self.moving = (dx != 0 or dy != 0)
        self.x += dx
        self.y += dy

        # 화면 밖으로 나가지 않도록 좌표를 [0, 화면크기-캐릭터크기] 범위로 제한한다.
        self.x = max(0, min(WIDTH - FRAME_SIZE * SCALE, self.x))
        self.y = max(0, min(HEIGHT - FRAME_SIZE * SCALE, self.y))

        self.update_animation(dt)

    def update_animation(self, dt):
        """
        움직이는 중일 때만 애니메이션 프레임을 진행시킨다.
        dt(경과 시간)를 계속 누적하다가 anim_speed(120ms)를 넘으면
        다음 프레임으로 넘어가는 방식 - "델타 타임 기반 애니메이션".
        """
        if self.moving:
            self.anim_timer += dt
            if self.anim_timer >= self.anim_speed:
                self.anim_timer = 0  # 타이머를 리셋하고 다음 프레임으로 진행
                prev = self.anim_index
                # % 연산으로 리스트 끝에 도달하면 다시 처음(0)으로 순환시킨다.
                self.anim_index = (self.anim_index + 1) % len(self.anim_frames)

                # 발이 실제로 땅에 닿는 프레임(0번=왼발, 2번=오른발)으로
                # "새로" 바뀌는 순간에만 발소리를 재생한다.
                # (1번 idle 프레임을 거쳐 다시 0/2번이 될 때만 소리가 나서
                #  자연스러운 두 박자 걸음 소리가 만들어진다)
                if self.anim_frames[self.anim_index] in (0, 2) and self.anim_frames[prev] not in (0, 2):
                    step_sound.play()
        else:
            # 멈춰 있을 때는 항상 "서 있는" idle 프레임(1번)으로 고정한다.
            # 그래야 다리가 벌어진 어정쩡한 자세에서 멈추지 않는다.
            self.anim_index = 1

    def draw(self, surface):
        """현재 방향과 애니메이션 프레임에 맞는 이미지를 잘라서 화면에 그린다."""
        frame_number = self.anim_frames[self.anim_index]
        image = get_frame(self.direction, frame_number)
        surface.blit(image, (self.x, self.y))


# 캐릭터를 화면 정중앙에 배치 (캐릭터 크기의 절반만큼 빼서 중심이 맞도록)
player = Player(WIDTH // 2 - FRAME_SIZE, HEIGHT // 2 - FRAME_SIZE)

# ============================================================
# 게임 루프
# ============================================================
running = True
while running:
    # clock.tick(60): 초당 60프레임으로 제한하면서, 이전 프레임 이후
    # 흐른 시간(ms)을 반환한다. 이 값을 dt로 저장해 애니메이션 속도 계산에 쓴다.
    dt = clock.tick(60)

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            running = False

    player.handle_input(dt)

    screen.fill((40, 44, 52))
    player.draw(screen)

    pygame.display.flip()

pygame.quit()
sys.exit()

② 방향 판별 & 이동

handle_input()에서 눌린 방향키에 따라 self.direction을 갱신하고 좌표를 바꿉니다. elif 구조라서 한 번에 한 방향으로만 이동하도록 단순화했습니다. (대각선 이동은 이후 심화 자료에서 다룹니다.)

③ 애니메이션 프레임 전환

self.anim_timer += dt
if self.anim_timer >= self.anim_speed:
    self.anim_timer = 0
    self.anim_index = (self.anim_index + 1) % len(self.anim_frames)

dt는 clock.tick(60)이 반환하는 "직전 프레임 이후 흐른 시간(ms)"입니다. 이 값을 계속 더하다가 anim_speed(120ms)를 넘으면 타이머를 리셋하고 다음 프레임으로 넘어갑니다. 이렇게 하면 화면 프레임 속도(FPS)와 상관없이 항상 일정한 속도로 애니메이션이 재생됩니다.

자주 하는 실수 — 매 프레임마다 self.anim_index += 1을 그냥 실행하면, 60FPS에서는 애니메이션이 1초에 60번 바뀌어버려 캐릭터가 지나치게 빠르게 파르르 떨립니다. 반드시 누적 시간을 기준으로 프레임을 전환해야 합니다.

④ 가만히 있을 때 idle 프레임

방향키를 떼면 self.moving이 False가 되고, anim_index를 서 있는 프레임(1번, idle)으로 고정합니다. 그래야 캐릭터가 멈췄을 때 다리가 어정쩡하게 벌어진 프레임에서 멈추지 않습니다.

8심화: 캐릭터 이동 속도를 다르게 구현하기

위 실습 코드는 self.speed = 4처럼 "한 프레임에 몇 픽셀 움직일지"로 속도를 정했습니다. 애니메이션은 이미 dt(경과 시간) 기준으로 만들어서 프레임 속도와 무관하지만, 이동 자체는 여전히 프레임 수에 묶여 있습니다. 이 차이와, 걷기/달리기처럼 속도를 상황에 따라 다르게 만드는 방법을 살펴봅니다.

왜 "프레임당 픽셀" 방식은 문제가 될까?

방식코드특징
프레임당 고정 픽셀self.x += dx * speed한 프레임에 항상 speed픽셀 이동. 컴퓨터가 60FPS를 못 내고 30FPS로 떨어지면, 초당 이동 프레임 수가 절반이 되어 실제 이동 속도도 절반이 됩니다.
델타 타임(초당 픽셀)self.x += dx * speed * dt_secspeed를 "초당 몇 픽셀"로 정의. 프레임이 얼마나 자주 그려지든, 1초 동안 이동하는 총 거리는 항상 같습니다.
실습 A(카운트다운)에서 이미 썼던 개념 — 코드 설명 ③에서 애니메이션 프레임을 dt 누적으로 전환한 것과 완전히 같은 원리입니다. "누적 시간 기준으로 진행시킨다"는 아이디어를 애니메이션뿐 아니라 이동 자체에도 적용하는 것입니다.
dt_sec = clock.tick(60) / 1000
단위 변환clock.tick()은 밀리초(ms)를 반환합니다. "초당 픽셀" 속도와 곱하려면 1000으로 나눠 초(sec) 단위로 바꿔야 합니다.
계산식이번 프레임 이동 거리 = speed(px/sec) × dt_sec(sec). 예를 들어 speed=160이면 프레임이 얼마나 걸렸든 1초가 지나는 동안 총 160픽셀을 이동합니다.
주의좌표를 정수로만 관리하면 느린 속도에서 dx * speed * dt_sec가 0에 가까워 반올림 시 전혀 움직이지 않을 수 있습니다. 좌표는 float으로 저장하고, 화면에 그릴 때만 int()로 변환하세요.

걷기 / 달리기: 상황에 따라 속도를 다르게

같은 원리로 speed 값 자체를 조건에 따라 다르게 선택하면 걷기·달리기 같은 여러 이동 속도를 쉽게 구현할 수 있습니다. 아래 코드는 Shift 키를 누르고 있는 동안 더 빠른 run_speed를 사용하고, 달릴 때는 다리 애니메이션도 더 빠르게 재생해 속도감을 일치시킵니다.

player_movement_speed_demo.py
# ============================================================
# 심화 - 캐릭터 이동 속도를 다르게 구현하기
# ------------------------------------------------------------
# 실습 2는 "한 프레임에 몇 픽셀 이동할지"(speed=4)로 속도를 정했다.
# 이 방식은 프레임 속도(FPS)가 흔들리면 실제 이동 속도도 함께
# 흔들린다는 단점이 있다. 이번 데모는 속도를 "초당 몇 픽셀"로
# 바꿔서 프레임 속도와 무관하게 만들고(델타 타임 기반 이동),
# 나아가 Shift 키로 걷기/달리기 속도를 다르게 구현해본다.
# ============================================================

import pygame
import sys

pygame.init()
pygame.mixer.init()

WIDTH, HEIGHT = 640, 480
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("캐릭터 이동 속도 다르게 구현하기")
clock = pygame.time.Clock()
font = pygame.font.SysFont("malgungothic", 20)

FRAME_SIZE = 48
SCALE = 2

spritesheet = pygame.image.load("assets/player_spritesheet.png").convert_alpha()
step_sound = pygame.mixer.Sound("assets/step.wav")

# 실습 2와 동일한 스프라이트 시트 구조 (4행: 방향 / 3열: 애니메이션 프레임)
DIRECTIONS = {"down": 0, "left": 1, "right": 2, "up": 3}


def get_frame(direction, frame_index):
    """실습 2와 동일한 방식으로 스프라이트 시트 한 칸을 잘라 확대해서 반환한다."""
    row = DIRECTIONS[direction]
    col = frame_index
    rect = pygame.Rect(col * FRAME_SIZE, row * FRAME_SIZE, FRAME_SIZE, FRAME_SIZE)
    frame = spritesheet.subsurface(rect).copy()
    frame = pygame.transform.scale(frame, (FRAME_SIZE * SCALE, FRAME_SIZE * SCALE))
    return frame


class Player:
    """
    이동 속도를 '프레임당 픽셀'이 아니라 '초당 픽셀'로 관리한다.
    walk_speed / run_speed 는 모두 px/sec(초당 픽셀) 단위이다.
    """

    def __init__(self, x, y):
        # 좌표를 정수가 아닌 float(실수)로 저장한다.
        # 이동 거리(speed * dt_sec)가 1픽셀보다 작은 소수 값이 될 수 있는데,
        # 정수로만 관리하면 반올림 과정에서 값이 통째로 사라져 캐릭터가
        # 전혀 움직이지 않는 문제가 생길 수 있기 때문이다.
        self.x = float(x)
        self.y = float(y)

        self.walk_speed = 160.0   # 걷기: 초당 160픽셀 이동
        self.run_speed = 320.0    # 달리기(Shift): 초당 320픽셀 이동 (걷기의 정확히 2배)

        self.direction = "down"
        self.moving = False
        self.running = False   # 지금 "달리기" 상태인지 여부 (Shift를 누르고 있는지)

        self.anim_frames = [0, 1, 2, 1]
        self.anim_index = 0
        self.anim_timer = 0.0
        self.walk_anim_interval = 140   # 걸을 때: 140ms마다 다음 애니메이션 프레임
        self.run_anim_interval = 80     # 달릴 때: 80ms마다(더 짧게) -> 다리가 더 빨리 움직임

    def handle_input(self, dt_sec):
        """
        dt_sec: 이전 프레임 이후 흐른 시간(초 단위).
        게임 루프에서 clock.tick(60)의 반환값(ms)을 1000으로 나눠서 전달받는다.
        """
        keys = pygame.key.get_pressed()
        dx = dy = 0.0

        # ----- Shift 키: 달리기 여부를 매 프레임 새로 확인 -----
        # K_LSHIFT(왼쪽 Shift) 또는 K_RSHIFT(오른쪽 Shift) 둘 중 하나라도 눌려있으면 달리기.
        self.running = keys[pygame.K_LSHIFT] or keys[pygame.K_RSHIFT]
        # 현재 상태(걷기/달리기)에 맞는 속도를 그때그때 선택한다.
        current_speed = self.run_speed if self.running else self.walk_speed

        # 이동 "방향"만 -1, 0, 1로 표현하고, 실제 속도(픽셀/초)는 아래에서 곱한다.
        if keys[pygame.K_LEFT]:
            dx = -1
            self.direction = "left"
        elif keys[pygame.K_RIGHT]:
            dx = 1
            self.direction = "right"
        elif keys[pygame.K_UP]:
            dy = -1
            self.direction = "up"
        elif keys[pygame.K_DOWN]:
            dy = 1
            self.direction = "down"

        self.moving = (dx != 0 or dy != 0)

        # ----- 핵심: 속도(px/sec) x 시간(sec) = 이번 프레임에 이동할 거리 -----
        # 예를 들어 current_speed=160이고 dt_sec=0.016(약 60FPS 기준 1프레임)이면
        # 이번 프레임에는 160 * 0.016 = 2.56픽셀만큼만 이동한다.
        # 프레임이 얼마나 자주 그려지든, 1초 동안 누적되는 총 이동 거리는 항상
        # current_speed와 같아지므로 "프레임 속도와 무관한 이동"이 완성된다.
        self.x += dx * current_speed * dt_sec
        self.y += dy * current_speed * dt_sec

        self.x = max(0, min(WIDTH - FRAME_SIZE * SCALE, self.x))
        self.y = max(0, min(HEIGHT - FRAME_SIZE * SCALE, self.y))

        self.update_animation(dt_sec)

    def update_animation(self, dt_sec):
        if self.moving:
            # anim_timer는 ms 단위로 다루고 있으므로, 초 단위인 dt_sec에
            # 1000을 곱해서 다시 ms로 바꿔 누적한다.
            self.anim_timer += dt_sec * 1000
            # 달리는 중이면 더 짧은 간격(run_anim_interval)을, 걷는 중이면
            # 더 긴 간격(walk_anim_interval)을 선택해서 애니메이션 속도를
            # 실제 이동 속도와 시각적으로 맞춘다.
            interval = self.run_anim_interval if self.running else self.walk_anim_interval
            if self.anim_timer >= interval:
                self.anim_timer = 0
                prev_frame = self.anim_frames[self.anim_index]
                self.anim_index = (self.anim_index + 1) % len(self.anim_frames)
                new_frame = self.anim_frames[self.anim_index]
                if new_frame in (0, 2) and prev_frame not in (0, 2):
                    step_sound.play()
        else:
            self.anim_index = 1

    def draw(self, surface):
        frame_number = self.anim_frames[self.anim_index]
        image = get_frame(self.direction, frame_number)
        # float 좌표를 blit()에 그대로 넘겨도 pygame이 알아서 정수로
        # 처리해주지만, 명시적으로 화면에 그릴 때만 좌표를 쓰고
        # 내부 계산(self.x, self.y)은 계속 float로 유지하는 것이 정밀도에 좋다.
        surface.blit(image, (self.x, self.y))

    dt_sec = dt_ms / 1000.0     # 초 단위로 변환 (px/sec 속도 계산에 사용하기 위해)

참고: 대각선 이동 속도 보정

이번 실습은 elif 구조라 한 번에 한 방향으로만 움직이지만, 만약 상하좌우를 if문으로 각각 검사해 8방향(대각선 포함) 이동을 구현한다면 주의할 점이 하나 더 있습니다. 대각선으로 움직일 때 dx와 dy를 그대로 더하면 실제 이동 거리가 √2 ≈ 1.41배 빨라집니다(가로+세로 성분이 동시에 더해지기 때문). 이를 막으려면 이동 벡터의 길이를 1로 맞추는 정규화(normalize)가 필요합니다.

# pygame.math.Vector2를 쓰면 정규화를 한 줄로 처리할 수 있습니다
move_vec = pygame.math.Vector2(dx, dy)
if move_vec.length() > 0:
    move_vec = move_vec.normalize()
self.x += move_vec.x * current_speed * dt_sec
self.y += move_vec.y * current_speed * dt_sec
정규화(normalize)란? 벡터의 방향은 그대로 두고 길이(크기)만 1로 만드는 것입니다. 대각선 이동처럼 (dx, dy) = (1, 1)인 경우 길이는 √2인데, 정규화하면 (0.707, 0.707)이 되어 어느 방향으로 움직이든 실제 이동 거리가 동일해집니다.

참고 — 벽에 막히게 만드는 방법 — 캐릭터를 이동시키기 전에 pygame.Rect.colliderect()로 다음 위치가 벽과 겹치는지 먼저 확인하면 됩니다. 이때 x축과 y축을 따로 처리하는 것이 핵심입니다: x축으로 이동해보고 벽과 겹치면 그 이동만 취소(또는 벽 경계에 맞춰 되돌리기) → y축도 같은 방식으로 처리. 이렇게 두 축을 나눠서 처리하면, 대각선으로 벽에 다가가도 한쪽 축은 계속 이동할 수 있어 벽을 따라 자연스럽게 미끄러지듯 움직입니다. MAZE_OFFSET_X = 32
MAZE_OFFSET_Y = 76

WIDTH, HEIGHT = MAZE_PIXEL_WIDTH + MAZE_OFFSET_X * 2, MAZE_PIXEL_HEIGHT + MAZE_OFFSET_Y + 32
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("통합 과제 - 미로 탈출 타임어택")
clock = pygame.time.Clock()

spritesheet = pygame.image.load("assets/player_spritesheet.png").convert_alpha()

# 벽/깃발 이미지를 미로 타일 크기(32x32)에 맞춰 미리 한 번만 축소해둔다.
wall_img = pygame.transform.scale(wall_img, (TILE, TILE))
goal_img = pygame.transform.scale(goal_img, (TILE, TILE))

FRAME_SIZE = 48          # 스프라이트 시트 한 칸의 원본 크기
PLAYER_SIZE = TILE - 2   # 캐릭터를 미로 통로보다 살짝 작게 그려서 여유를 준다
DIRECTIONS = {"down": 0, "left": 1, "right": 2, "up": 3}


def get_frame(direction, frame_index):
    """스프라이트 시트에서 한 칸을 잘라 PLAYER_SIZE 크기로 축소해서 반환한다."""
    row = DIRECTIONS[direction]
    col = frame_index
    rect = pygame.Rect(col * FRAME_SIZE, row * FRAME_SIZE, FRAME_SIZE, FRAME_SIZE)
    frame = spritesheet.subsurface(rect).copy()
    frame = pygame.transform.scale(frame, (PLAYER_SIZE, PLAYER_SIZE))
    return frame


# ----- 미로 문자열을 실제 좌표/Rect로 변환 -----
walls = []
start_pos = (MAZE_OFFSET_X, MAZE_OFFSET_Y)
goal_rect = None

for row_index, row in enumerate(MAZE_LAYOUT):
    for col_index, ch in enumerate(row):
        x = MAZE_OFFSET_X + col_index * TILE
        y = MAZE_OFFSET_Y + row_index * TILE
        if ch == "#":
            walls.append(pygame.Rect(x, y, TILE, TILE))
        elif ch == "S":
            start_pos = (x + (TILE - PLAYER_SIZE) // 2, y + (TILE - PLAYER_SIZE) // 2)
        elif ch == "G":
            goal_rect = pygame.Rect(x, y, TILE, TILE)


class Player:
    """실습 2의 Player 클래스에 '충돌 판정용 Rect 반환' 기능을 추가한 버전."""

    def __init__(self, x, y):
        self.x = x
        self.y = y
        self.speed = 4
        self.direction = "down"
        self.moving = False

        self.anim_frames = [0, 1, 2, 1]
        self.anim_index = 0
        self.anim_timer = 0
        self.anim_speed = 130

    def rect(self):
        """현재 위치 기준의 충돌 판정용 Rect. 벽/목표 지점과의 colliderect()에 사용한다."""
        return pygame.Rect(self.x, self.y, PLAYER_SIZE, PLAYER_SIZE)

    def try_move(self, dx, dy, walls):
        """
        이동을 시도하되, x축과 y축을 따로 처리해서 벽에 막히면
        그 축의 이동만 취소한다. (대각선으로 벽에 다가가도 다른 축으로는
        계속 미끄러지듯 이동할 수 있게 하기 위함)
        """
        # ---- x축 시도 ----
        self.x += dx
        temp_rect = self.rect()
        for wall in walls:
            if temp_rect.colliderect(wall):
                self.x -= dx  # 겹치면 이동을 취소(원래 위치로 복귀)
                break

        # ---- y축 시도 ----
        self.y += dy
        temp_rect = self.rect()
        for wall in walls:
            if temp_rect.colliderect(wall):
                self.y -= dy
                break

    def handle_input(self, walls):
        keys = pygame.key.get_pressed()
        dx = dy = 0
        if keys[pygame.K_LEFT]:
            dx = -self.speed
            self.direction = "left"
        elif keys[pygame.K_RIGHT]:
            dx = self.speed
            self.direction = "right"
        elif keys[pygame.K_UP]:
            dy = -self.speed
            self.direction = "up"
        elif keys[pygame.K_DOWN]:
            dy = self.speed
            self.direction = "down"

        self.moving = (dx != 0 or dy != 0)
        if self.moving:
            self.try_move(dx, dy, walls)

    def update_animation(self, dt):
        if self.moving:
            self.anim_timer += dt
            if self.anim_timer >= self.anim_speed:
                self.anim_timer = 0
                prev = self.anim_index
                self.anim_index = (self.anim_index + 1) % len(self.anim_frames)
                if self.anim_frames[self.anim_index] in (0, 2) and self.anim_frames[prev] not in (0, 2):
                    step_sound.play()
        else:
            self.anim_index = 1

    def draw(self, surface):
        image = get_frame(self.direction, self.anim_frames[self.anim_index])
        surface.blit(image, (self.x, self.y))


# ----- 게임 상태 관리 -----
# "countdown" -> "playing" -> "success" 또는 "fail"
COUNTDOWN_EVENT = pygame.USEREVENT + 1
TIME_LIMIT = 15  # 제한시간(초)


def start_new_round():
    """카운트다운부터 다시 시작할 때 필요한 모든 상태를 초기화한다."""
    pygame.time.set_timer(COUNTDOWN_EVENT, 1000)
    return {
        "state": "countdown",
        "count": 5,
        "player": Player(*start_pos),
        "start_ticks": 0,       # "playing" 상태로 바뀌는 순간 기록됨
        "result_elapsed": 0.0,  # 성공/실패 시점의 경과 시간(표시용)
    }


game = start_new_round()

# ============================================================
# 게임 루프
# ============================================================
running = True
while running:
    dt = clock.tick(60)

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False
            elif event.key == pygame.K_r and game["state"] in ("success", "fail"):
                game = start_new_round()

        elif event.type == COUNTDOWN_EVENT and game["state"] == "countdown":
            if game["count"] > 1:
                game["count"] -= 1
                beep_sound.play()
            else:
                # 카운트다운 종료 -> 플레이 시작
                go_sound.play()
                pygame.time.set_timer(COUNTDOWN_EVENT, 0)  # 타이머 정지
                game["state"] = "playing"
                game["start_ticks"] = pygame.time.get_ticks()  # 제한시간 계산의 기준 시각

    # ----- 상태별 갱신 로직 -----
    if game["state"] == "playing":
        player = game["player"]
        player.handle_input(walls)
        player.update_animation(dt)

        # 제한시간 계산: (현재시각 - 시작시각)을 1000으로 나눠 초 단위로 변환
        elapsed = (pygame.time.get_ticks() - game["start_ticks"]) / 1000
        remaining = TIME_LIMIT - elapsed

        if player.rect().colliderect(goal_rect):
            game["state"] = "success"
            game["result_elapsed"] = elapsed
            success_sound.play()
        elif remaining <= 0:
            game["state"] = "fail"
            game["result_elapsed"] = TIME_LIMIT
            fail_sound.play()

    # ----- 화면 그리기 -----
    screen.fill((30, 33, 44))

    # 미로(벽) 그리기
    for wall in walls:
        screen.blit(wall_img, wall)
    # 목표 깃발 그리기
    screen.blit(goal_img, goal_rect)
    # 플레이어 그리기 (카운트다운 중에도 시작 위치에 가만히 서 있는 모습을 보여준다)
    game["player"].draw(screen)

    # ----- 상태별 화면 요소 -----
    if game["state"] == "countdown":
        text = big_font.render(str(game["count"]), True, (255, 220, 80))
        screen.blit(text, text.get_rect(center=(WIDTH // 2, 40)))

    elif game["state"] == "playing":
        elapsed = (pygame.time.get_ticks() - game["start_ticks"]) / 1000
        remaining = max(0, TIME_LIMIT - elapsed)
        color = (239, 68, 68) if remaining <= 5 else (230, 230, 235)
        timer_text = font.render(f"남은 시간: {remaining:.1f}초", True, color)
        screen.blit(timer_text, (16, 16))
        hint = small_font.render("방향키로 이동해 깃발(G)까지 도달하세요", True, (150, 155, 170))
        screen.blit(hint, (16, 44))

    elif game["state"] == "success":
        msg1 = big_font.render("SUCCESS!", True, (34, 197, 94))
        msg2 = font.render(f"클리어 시간: {game['result_elapsed']:.1f}초", True, (230, 230, 235))
        msg3 = small_font.render("R 키를 누르면 다시 시작합니다", True, (150, 155, 170))
        screen.blit(msg1, msg1.get_rect(center=(WIDTH // 2, HEIGHT // 2 - 20)))
        screen.blit(msg2, msg2.get_rect(center=(WIDTH // 2, HEIGHT // 2 + 30)))
        screen.blit(msg3, msg3.get_rect(center=(WIDTH // 2, HEIGHT // 2 + 60)))

    elif game["state"] == "fail":
        msg1 = big_font.render("TIME OVER", True, (239, 68, 68))
        msg2 = font.render("제한시간 안에 도착하지 못했습니다", True, (230, 230, 235))
        msg3 = small_font.render("R 키를 누르면 다시 시작합니다", True, (150, 155, 170))
        screen.blit(msg1, msg1.get_rect(center=(WIDTH // 2, HEIGHT // 2 - 20)))
        screen.blit(msg2, msg2.get_rect(center=(WIDTH // 2, HEIGHT // 2 + 30)))
        screen.blit(msg3, msg3.get_rect(center=(WIDTH // 2, HEIGHT // 2 + 60)))

    pygame.display.flip()

pygame.quit()
sys.exit()
